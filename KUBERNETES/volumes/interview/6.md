## Complete PV Lifecycle Flow:

```
1. Admin creates PV → Status: Available
2. Developer creates PVC → Binds to PV → Status: Bound
3. PVC is deleted:
   - Recycle policy → Status: Available (data erased)
   - Retain policy → Status: Released (data preserved)
   - Delete policy → PV deleted
4. Released PV → Admin manual intervention → Status: Available
5. Storage error → Status: Failed (can recover)
```
