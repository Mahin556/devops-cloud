## PV is cluster-wide. Can one PV be used in two namespaces simultaneously?

**Answer:** **NO**

### Explanation:
- PV scope IS cluster-wide (yes)
- But once a PV is **bound** to a PVC in one namespace
- Only pods in that SAME namespace can use it
- A different namespace CANNOT bind to the same PV at the same time

### Key Clarification:
- PV is cluster-wide → means it's visible across all namespaces
- But binding is namespace-specific
- One PV → One PVC → One Namespace at a time
