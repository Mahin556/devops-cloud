## What is ClusterIP Service?

**Definition:** ClusterIP is the **default** service type that provides a **stable virtual IP** accessible **only inside the cluster**.

**Use Case:**
- Internal communication between microservices
- Example: WordPress (frontend) connecting to MySQL (backend)
- Database should NOT be exposed to the outside world
- So database service type = ClusterIP

**Key Point:**
- ClusterIP is NOT accessible from outside the cluster
- It's for internal pod-to-pod communication only
