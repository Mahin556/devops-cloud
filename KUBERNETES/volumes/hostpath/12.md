```yaml
apiVersion: v1
kind: Pod
metadata:
  name: hostpath-demo
spec:
  containers:
  - name: demo
    image: nginx
    volumeMounts:
    - name: host-storage
      mountPath: /usr/share/nginx/html

  volumes:
  - name: host-storage
    hostPath:
      path: /data/html
      type: Directory
```
`/data/html` must exits first othetwise:
