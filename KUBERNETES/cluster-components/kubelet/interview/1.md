## Question 4: What is Kubelet?

**Answer:** **kubelet** is an agent that runs on **every worker node** in a Kubernetes cluster. It ensures that containers described in PodSpecs are running and healthy.

### Key Responsibilities:

| Responsibility | Description |
|----------------|-------------|
| **Pod Management** | Receives PodSpecs from API server and ensures containers are running |
| **Health Checks** | Performs liveness and readiness probes |
| **Resource Monitoring** | Reports node and pod metrics |
| **Volume Management** | Mounts volumes for pods |
| **Node Registration** | Registers the node with the API server |
| **Heartbeat** | Sends regular heartbeats to control plane |

### How It Works:
```
API Server → kubelet → Container Runtime (containerd/CRI-O) → Containers
```

### Key Point:
"kubelet is the **primary node agent** - without it, the node cannot participate in the cluster."
