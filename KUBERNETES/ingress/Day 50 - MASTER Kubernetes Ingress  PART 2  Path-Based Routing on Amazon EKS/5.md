In Kubernetes Ingress, **`pathType: Prefix`** and **`pathType: Exact`** control **how the URL path is matched** before routing traffic to a Service.

This is part of the Ingress rules in **Kubernetes**.

---

# 1. Prefix

**Prefix = match the beginning of the path**

If the request path **starts with** the given value, it matches.

Example:

```yaml
paths:
- path: /api
  pathType: Prefix
```

Matches:

```text
/api
/api/
/api/users
/api/v1/data
```

Does NOT match:

```text
/app
```

Think:

```text
/api*  → matches everything starting with /api
```

---

# 2. Exact

**Exact = match the path exactly**

The request path must be **identical**.

Example:

```yaml
paths:
- path: /api
  pathType: Exact
```

Matches:

```text
/api
```

Does NOT match:

```text
/api/
/api/users
/api/v1
```

Think:

```text
/api  → only this exact path
```

---

# 3. Side-by-Side Example

```yaml
rules:
- http:
    paths:
    - path: /iphone
      pathType: Prefix
      backend:
        service:
          name: iphone-service
          port:
            number: 80

    - path: /android
      pathType: Exact
      backend:
        service:
          name: android-service
          port:
            number: 80
```

### Requests:

| URL                | Matches  |
| ------------------ | -------- |
| `/iphone`          | Prefix ✅ |
| `/iphone/settings` | Prefix ✅ |
| `/android`         | Exact ✅  |
| `/android/v1`      | Exact ❌  |

---

# 4. When to Use Which

## Use Prefix

When you want a **whole section** of a site:

```text
/api/*
/app/*
/blog/*
```

## Use Exact

When you want **one specific path**:

```text
/login
/health
/status
```

---

# 5. Default Route Example

```yaml
- path: /
  pathType: Prefix
```

This matches:

```text
Everything
```

That’s why `/` with Prefix becomes the **default route**.

---

# 6. Key Difference (Simple)

```text
Prefix → starts with
Exact  → equals
```
