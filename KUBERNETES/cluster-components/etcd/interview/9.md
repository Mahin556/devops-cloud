## Why Only Leader Can Write?

```
Write Request Flow:

1. Client sends write to any etcd node
2. If node is FOLLOWER → forwards to LEADER
3. LEADER writes to its log
4. LEADER replicates to all followers
5. When majority acknowledges → commit
6. Return success to client

┌─────────┐     ┌─────────┐     ┌─────────┐
│Client   │────►│Follower │     │ LEADER  │
│         │     │ (Node A)│────►│ (Node B)│
└─────────┘     └─────────┘     └────┬────┘
                                      │
                     Replicate to followers
                                      │
                          ┌───────────┼───────────┐
                          ▼           ▼           ▼
                     ┌─────────┐ ┌─────────┐ ┌─────────┐
                     │ Node A  │ │ Node B  │ │ Node C  │
                     │ ACK ✓   │ │Commit   │ │ ACK ✓   │
                     └─────────┘ └─────────┘ └─────────┘
                         Majority (2/3) acknowledged → COMMIT
```
