### Why Quorum is Needed?

#### Two Types of Services in a Cluster:

**1. Active-Active Services (No Quorum Needed):**
- Example: Web servers, API servers
- Multiple instances can run simultaneously
- All instances can handle requests at the same time
- A load balancer distributes traffic among them
- No risk of data corruption because they don't write shared data
- If one fails, others continue working seamlessly

```
Request → Load Balancer → Web Server 1 (Active)
                         → Web Server 2 (Active)  
                         → Web Server 3 (Active)
```

**2. Active-Passive Services (Quorum Required):**
- Example: etcd (database that writes data)
- Only ONE instance can write at a time
- If multiple instances write simultaneously → **data corruption**
- This is where Split Brain becomes a problem
- To prevent the spilt brain issue and data corruptiono issue we need a quorum.
