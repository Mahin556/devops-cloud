## You have a microservices-based application consisting of multiple containers. How would you deploy and manage this application in Kubernetes?

**Answer:**

### Step-by-Step Approach:

**Step 1: Create Deployment Objects for Each Microservice**
- Create a separate deployment for each component of the application
- Within each deployment, specify:
  - Container image to use
  - Port numbers
  - Resource requests and limits
  - Environment variables and configuration settings

**Step 2: Create Services to Expose the Microservices**
- Deployments create the pods, but you need Services to access them
- Services expose the microservices to:
  - Other components within the cluster
  - External users (if needed)
- Services allow you to work with the application running inside the pods

**Summary:** Each microservice gets its own Deployment and Service. Deployments manage the pod lifecycle, and Services provide network access.
