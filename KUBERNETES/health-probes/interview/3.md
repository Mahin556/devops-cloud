#### Q13: You need to ensure that a specific pod remains operational at all times. How to make sure that pod is always running?
**Detailed Answer:**
Use a **Liveness Probe**.
- **The Problem:** A container is "Up" (process running) but "Deadlocked" (application stuck in an infinite loop or thread lock).
- **The Solution:** Liveness Probe performs a periodic check.
- **Types:**
    - `httpGet`: Checks if endpoint returns 200 OK.
    - `tcpSocket`: Checks if port is open.
    - `exec`: Runs a command inside container (exit 0 = healthy).
- **Configuration (Critical Parameters):**
    - `initialDelaySeconds`: Wait before first probe (allow app to boot).
    - `periodSeconds`: How often to probe.
    - `failureThreshold`: How many consecutive failures before restarting.
