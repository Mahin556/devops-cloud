## How to Actually Expand a PV?

Once all three conditions are met, expansion is simple:

**Step 1: Edit the PVC and increase storage request:**
```bash
kubectl edit pvc <pvc-name>
```

Change the `spec.resources.requests.storage` value:
```yaml
spec:
  resources:
    requests:
      storage: 100Gi  # Increased from 50Gi
```

**Step 2: Wait for expansion to complete:**
```bash
kubectl get pvc <pvc-name>
```

The PVC will show a condition `Resizing` and then the new size. The PV will also update its capacity.

**Step 3: Verify:**
```bash
kubectl get pv <pv-name>
kubectl describe pvc <pvc-name>
```
