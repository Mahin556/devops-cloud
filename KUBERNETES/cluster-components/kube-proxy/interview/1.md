### Describe the role of a Proxy in Kubernetes.

## Role of Kube-Proxy in Kubernetes

Kube-Proxy is a network component that runs on every worker node in a Kubernetes cluster.

Its main role is to manage network communication and enable access to Kubernetes Services.

---

## Functions of Kube-Proxy

* Monitors:

  * Services
  * Endpoints

* Creates and updates network rules on the node.

* Handles:

  * Pod-to-Service communication
  * Internal load balancing
  * Traffic forwarding

---

## How It Works

1. A Service is created in Kubernetes.

2. Kube-Proxy detects the Service and Pod endpoints.

3. It configures network rules using:

   * iptables
   * IPVS

4. Traffic is forwarded to the correct Pod.

---

## Benefits

* Enables service discovery
* Provides internal load balancing
* Maintains network routing between Pods and Services

---

### Simple Interview Answer

“Kube-Proxy is a Kubernetes networking component that runs on each node and manages network rules for Services and Pods. It forwards traffic to the correct Pods and enables internal load balancing and service communication.”
