#### Q11: What is the difference between ConfigMaps and Secrets?
| Feature | ConfigMap | Secret |
| :--- | :--- | :--- |
| **Purpose** | Non-confidential configuration data | Small amounts of sensitive data |
| **Storage** | Plain text in etcd (unless etcd encryption enabled) | Base64 encoded in etcd (Optionally encrypted at rest) |
| **Size Limit** | 1 MiB | 1 MiB |
| **Examples** | `.env` file variables, nginx.conf | Passwords, API Tokens, TLS Private Keys |
| **Security** | Easily visible in `kubectl describe` output. | Values are hidden by default in `kubectl describe` and `kubectl get -o yaml` (shows `***`). |
