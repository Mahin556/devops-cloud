###  What are Persistent Volumes (PVs) and PersistentVolumeClaims (PVCs)?

## Persistent Volumes (PV) and PersistentVolumeClaims (PVC) in Kubernetes

Persistent storage in Kubernetes is managed using:

* Persistent Volumes (PV)
* PersistentVolumeClaims (PVC)

---

## Persistent Volume (PV)

A Persistent Volume is a storage resource available in the Kubernetes cluster.

It can be:

* Created manually by an administrator
* Dynamically provisioned using a StorageClass

A PV exists independently of Pods.

### Examples

* NFS storage
* AWS EBS
* Azure Disk
* Ceph storage

---

## PersistentVolumeClaim (PVC)

A PVC is a request for storage made by a user or application.

It specifies:

* Required storage size
* Access mode
* Storage class

Kubernetes automatically binds the PVC to a suitable PV.

---

## Relationship

```text id="5m2p8"
Pod → PVC → PV → Physical Storage
```

* Pod uses PVC
* PVC requests storage
* PV provides storage

---

## Benefits

* Persistent data storage
* Storage abstraction
* Dynamic provisioning
* Decouples storage from applications

---

### Simple Interview Answer

“In Kubernetes, a Persistent Volume (PV) is a cluster storage resource, while a PersistentVolumeClaim (PVC) is a request for storage by a Pod or application. PVCs consume PVs to provide persistent storage to containers.”
