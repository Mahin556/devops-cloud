## Ingress in Kubernetes

Ingress is a Kubernetes API object used to manage external access to services inside a Kubernetes cluster, mainly for HTTP and HTTPS traffic.

It provides Layer 7 routing and allows traffic routing based on:

* Hostnames
* URL paths

### Example

* `api.example.com`
* `/users`

Ingress helps expose multiple services using a single external IP address.

---

## Ingress Controller

An Ingress Controller is the component that actually implements and manages the Ingress rules.

It works like:

* Reverse Proxy
* Load Balancer

Popular Ingress Controllers:

* NGINX
* Traefik

Without an Ingress Controller, Ingress rules do not work.

---

## Main Benefits

* Centralized traffic management
* Path-based and host-based routing
* SSL/TLS termination
* Load balancing
* Reduced need for multiple LoadBalancers

---

### Simple Interview Answer

“In Kubernetes, Ingress is an API object used to manage external HTTP/HTTPS access to services using routing rules based on hostnames or paths. An Ingress Controller implements these rules and acts as a reverse proxy or load balancer.”
