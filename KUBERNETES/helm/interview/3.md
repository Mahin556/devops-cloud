## 28. What is a Helm Chart, and How is it Used?

A Helm Chart is a packaged collection of Kubernetes resource files used to deploy and manage applications in Kubernetes.

Helm Charts are used with Helm, which is often called:

* The package manager for Kubernetes.

---

# What a Helm Chart Contains

A Helm Chart includes all Kubernetes YAML files needed to deploy an application, such as:

* Deployments
* Services
* ConfigMaps
* Secrets
* Ingress resources
* StatefulSets

---

# Purpose of Helm Charts

Helm simplifies:

* Application deployment
* Versioning
* Upgrades
* Rollbacks
* Configuration management

Instead of manually applying multiple YAML files, you deploy everything as:

* One reusable package

---

# Example Use Case

Deploying applications like:

* NGINX
* Prometheus
* Jenkins
* MySQL

using a single command.

---

# Basic Helm Chart Structure

```text id="5m2p8"
mychart/
├── Chart.yaml
├── values.yaml
├── templates/
│   ├── deployment.yaml
│   ├── service.yaml
│   └── ingress.yaml
```

---

# Important Files

| File          | Purpose                      |
| ------------- | ---------------------------- |
| `Chart.yaml`  | Chart metadata               |
| `values.yaml` | Default configuration values |
| `templates/`  | Kubernetes YAML templates    |

---

# How Helm Works

Helm uses:

* Templates
* Variables

to dynamically generate Kubernetes manifests.

---

# Example Variable Usage

## values.yaml

```yaml id="8k1n4"
replicaCount: 3
image:
  repository: nginx
```

---

## deployment.yaml

```yaml id="3x7q2"
replicas: {{ .Values.replicaCount }}
```

Helm replaces template variables during deployment.

---

# Deploying a Helm Chart

## Install Chart

```bash id="6v1m5"
helm install myapp ./mychart
```

---

## Upgrade Application

```bash id="2k8n7"
helm upgrade myapp ./mychart
```

---

## Rollback Release

```bash id="4p7m1"
helm rollback myapp 1
```

---

# Benefits of Helm Charts

* Simplifies Kubernetes deployments
* Reusable application templates
* Easy upgrades and rollbacks
* Environment-specific configuration
* Version control for deployments

---

# Helm Release Concept

When a chart is installed:

* Helm creates a Release

A release is:

* A running instance of a chart inside the cluster.
