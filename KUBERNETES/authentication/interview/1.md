## What is the name of the default superuser of the Kubernetes API server?

**Answer:** `kubernetes-admin`

- This is similar to `root` in Linux or `Administrator` in Windows
- The superuser's certificate is stored in `/etc/kubernetes/admin.conf`
- By default, this user uses **certificate-based authentication**
- The admin.conf file contains the client certificate, key, and CA certificate

**How to use:**
```bash
# Default location
export KUBECONFIG=/etc/kubernetes/admin.conf

# Or copy to user's home
mkdir -p ~/.kube
cp /etc/kubernetes/admin.conf ~/.kube/config
```
