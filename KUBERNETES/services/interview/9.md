## How to Create a Service for a Pod?

### Command:
```bash
kubectl expose pod <pod-name> --name=<service-name> --port=<port> --target-port=<target-port>
```

### Example:
```bash
kubectl expose pod ram --name=my-service --port=80 --target-port=80
```

### Two Port Numbers:
| Port | Description | Can Choose? |
|------|-------------|-------------|
| **--port** | Service/Proxy port | YES (you can choose) |
| **--target-port** | Container/Application port | NO (must match app port) |

### Key Point:
- The first port (`--port`) is the **kube-proxy's port** - you can choose any
- The second port (`--target-port`) is the **container's application port** - must match your app
- Traffic comes to the proxy port and is redirected to the target port

### Default Service Type:
- If no type is specified, **ClusterIP** is created by default
