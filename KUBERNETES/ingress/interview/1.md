## Container uses port 8080, but browser uses port 80. How to forward from container to service to Ingress to browser?

**Answer:**

- **Ingress** exposes port 80 externally for browser access
- Ingress connects to a **service** that listens on port 8080
- The service forwards to the **container** on port 8080
- Ingress Controller listens on port 80 by default
- Configured in Ingress resources

**Flow:**
```
Browser (Port 80) → Ingress → Service (Port 8080) → Container (Port 8080)
```
