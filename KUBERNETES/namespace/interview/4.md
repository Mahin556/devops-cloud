## Your organization wants to host multiple applications with varying security and resource requirements in the same Kubernetes cluster. How would you implement multi-tenancy?

**Answer:**

### Using Namespaces for Logical Partitioning:

**1. Namespaces:**
- Create logical partitions within the same cluster
- Isolate applications from each other

**2. Resource Quotas:**
- Enforce resource limits per namespace
- Prevent one tenant from consuming all resources

**3. Network Policies:**
- Isolate and secure resources
- Control communication between namespaces

**4. RBAC (Role-Based Access Control):**
- Restrict access based on user roles
- Control permissions per namespace

### Summary:
"Namespaces provide isolation, resource quotas prevent resource contention, network policies secure communication, and RBAC controls access—all working together for multi-tenancy."
