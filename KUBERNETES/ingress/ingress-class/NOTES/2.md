There are several ways to change an **IngressClass**, depending on what exactly you want to change.

---

# Option 1: Change the `ingressClassName` of an existing Ingress (Most Common)

Suppose your current Ingress is:

```yaml
spec:
  ingressClassName: nginx
```

and you want to use:

```yaml
spec:
  ingressClassName: my-ingress-nginx
```

### Method 1: Edit the resource

```bash
kubectl edit ingress blogging-ingress
```

Change:

```yaml
spec:
  ingressClassName: nginx
```

to

```yaml
spec:
  ingressClassName: my-ingress-nginx
```

Save and exit.

---

### Method 2: Apply an updated YAML

Modify your manifest:

```yaml
spec:
  ingressClassName: my-ingress-nginx
```

Then:

```bash
kubectl apply -f ingress.yaml
```

---

# Option 2: Patch the Ingress

You can change it without opening an editor:

```bash
kubectl patch ingress blogging-ingress \
  --type='merge' \
  -p '{"spec":{"ingressClassName":"my-ingress-nginx"}}'
```

Verify:

```bash
kubectl get ingress blogging-ingress -o yaml | grep ingressClassName
```

Output:

```text
ingressClassName: my-ingress-nginx
```

---

# Option 3: Change the Default IngressClass

Check existing classes:

```bash
kubectl get ingressclass
```

Example:

```text
NAME                 CONTROLLER
nginx                k8s.io/ingress-nginx
my-ingress-nginx     k8s.io/ingress-nginx
```

If you want `my-ingress-nginx` to become the default:

```bash
kubectl annotate ingressclass my-ingress-nginx \
ingressclass.kubernetes.io/is-default-class="true"
```

If another class is already the default, remove its annotation first:

```bash
kubectl annotate ingressclass nginx \
ingressclass.kubernetes.io/is-default-class-
```

Notice the trailing `-`, which removes the annotation.

Now new Ingress resources **without** an `ingressClassName` will use `my-ingress-nginx`.

---

# Option 4: Rename an IngressClass

You **cannot rename** an existing `IngressClass`.

For example, you cannot change:

```text
nginx
```

to

```text
my-ingress-nginx
```

Instead:

1. Create a new `IngressClass`.
2. Update all Ingress resources to use the new class.
3. Delete the old `IngressClass` if it's no longer needed.

# Verify Which Controller Is Handling Your Ingress

Check the Ingress:

```bash
kubectl describe ingress blogging-ingress
```

Look for:

```text
Ingress Class: my-ingress-nginx
```

Or:

```bash
kubectl get ingress
```

Example:

```text
NAME                CLASS
blogging-ingress    my-ingress-nginx
```

---

# Verify Available IngressClasses

```bash
kubectl get ingressclass
```

Example:

```text
NAME                 CONTROLLER
nginx                k8s.io/ingress-nginx
my-ingress-nginx     k8s.io/ingress-nginx
```
