If you're serving files from:

```nginx
location /welcome {
    root /usr/share/nginx/html/welcome;
    index index.html index.htm;
}
```

and want it to behave like a Single Page Application (SPA), add `try_files`:

```nginx
location /welcome {
    root /usr/share/nginx/html;
    index index.html index.htm;
    try_files $uri $uri/ /welcome/index.html;
}
```

### Important

Your current configuration:

```nginx
root /usr/share/nginx/html/welcome;
```

is **not recommended** because NGINX appends the request URI to the `root`.

For example:

```
Request:
GET /welcome/index.html
```

NGINX looks for:

```
/usr/share/nginx/html/welcome/welcome/index.html
```

Notice the duplicated `welcome`, which is usually not what you want.

### Recommended approaches

#### Option 1 (Recommended): Use `root`

Directory:

```
/usr/share/nginx/html/
└── welcome/
    ├── index.html
    ├── env.js
    └── style.css
```

Config:

```nginx
location /welcome {
    root /usr/share/nginx/html;
    index index.html;
    try_files $uri $uri/ /welcome/index.html;
}
```

#### Option 2: Use `alias`

```nginx
location /welcome {
    alias /usr/share/nginx/html/welcome/;
    index index.html;
    try_files $uri $uri/ /index.html;
}
```

With `alias`, the fallback should be `/index.html` because the URI prefix (`/welcome`) has already been mapped to the aliased directory.

If you're also generating `env.js`, place it in:

```
/usr/share/nginx/html/welcome/env.js
```

and reference it in your HTML as:

```html
<script src="/welcome/env.js"></script>
```

or simply:

```html
<script src="env.js"></script>
```

if `index.html` and `env.js` are in the same directory.
