## Load Balancing in Kubernetes

**Question:** How can Kubernetes help with efficient distribution of workloads?

**Answer:**

Kubernetes has built-in load balancing capabilities:
- If one node has too much pressure or health issues, Kubernetes distributes the workload
- If a node gets killed, a new node/pod is created and work gets distributed
- Kubernetes acts as an orchestration tool for workload distribution

### Internal vs External Load Balancer:

| Type | Function |
|------|----------|
| **Internal Load Balancer** | Balances loads and allocates pods within a node; distributes work between pods on the same node |
| **External Load Balancer** | Directs traffic from external sources to backend pods; distributes work between nodes |
