## Your organization wants to prevent resource contention and ensure fair resource allocation across different teams or projects. How would you implement resource quotas and limits?

**Answer:**

### Using Resource Quotas:

**What Resource Quotas Do:**
- Put limitations on resource utilization within namespaces
- Define maximum:
  - CPU utilization
  - Memory utilization
  - Storage utilization

**How It Works:**
- Specify maximum resource quotas for each namespace
- Prevent individual workloads from monopolizing cluster resources
- Ensure equitable resource distribution

**Example:**
```yaml
apiVersion: v1
kind: ResourceQuota
metadata:
  name: compute-quota
  namespace: team-a
spec:
  hard:
    requests.cpu: "10"
    requests.memory: 20Gi
    limits.cpu: "20"
    limits.memory: 40Gi
```
