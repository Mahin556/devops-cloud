## Pods fail health checks, resulting in restarts or unavailability.

### Troubleshooting Steps:

```bash
# Step 1: Debug probe endpoints
kubectl exec -it <pod-name> -- curl localhost:<probe-port>/<probe-path>

# Step 2: Adjust probe configuration
# Example:
livenessProbe:
  httpGet:
    path: /healthz
    port: 8080
  initialDelaySeconds: 20

# Step 3: Redeploy pods
kubectl rollout restart deployment <deployment-name>
```

### Common Causes:
- Application startup too slow
- Wrong probe path or port
- initialDelaySeconds too short
