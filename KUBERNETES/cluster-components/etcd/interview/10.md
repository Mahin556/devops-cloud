## How Quorum Prevents Split Brain in etcd?

### Network Partition Scenario (3 nodes):

```
Before Partition:
┌─────────┐    ┌─────────┐    ┌─────────┐
│Master 1 │◄──►│Master 2 │◄──►│Master 3 │
│etcd     │    │etcd (L) │    │etcd     │
│Member   │    │LEADER   │    │Member   │
│Vote=1   │    │Vote=1   │    │Vote=1   │
└─────────┘    └─────────┘    └─────────┘
  Total Votes=3, Quorum=2
```

```
Network Partition Occurs (Master 1 isolated):

Partition 1:              Partition 2:
┌─────────┐         ┌─────────┐    ┌─────────┐
│Master 1 │    ✗    │Master 2 │◄──►│Master 3 │
│etcd     │  Break  │etcd (L) │    │etcd     │
│Member   │         │LEADER   │    │Member   │
│Vote=1   │         │Vote=1   │    │Vote=1   │
└─────────┘         └─────────┘    └─────────┘
```

**What Happens Next:**

**Partition 2 (Has Quorum - 2 votes):**
1. Master 3 detects leader is missing (no heartbeats from Master 2)
2. BUT Master 2 and Master 3 CAN communicate
3. They discover they have 2 votes → quorum = 2 satisfied
4. They hold election if needed
5. **Partition 2 continues operating as the cluster**

**Partition 1 (No Quorum - 1 vote):**
1. Master 1 detects it's alone
2. It has only 1 vote → quorum = 2 NOT satisfied
3. **Master 1 CANNOT become leader**
4. Master 1 stops accepting writes
5. **Master 1 reboots and tries to rejoin the cluster**

**Result:** Only Partition 2 operates → No split brain!
