If a container is compromised and running with high privileges (especially as root), an attacker could potentially:

Access and modify application files inside the container.

Read sensitive data such as environment variables, API keys, tokens, or secrets stored in files.

Install malicious tools or backdoors inside the container.

Stop, start, or manipulate running processes.

Use the container to scan internal network services.

Attempt lateral movement to other pods or services in the cluster.

Abuse outbound network access to communicate with external command-and-control servers.

Escalate privileges if misconfigurations exist (e.g., privileged containers, excessive capabilities).

Exploit mounted volumes to access host files if improperly configured.

Attempt container escape if dangerous capabilities (like CAP_SYS_ADMIN) are present.
