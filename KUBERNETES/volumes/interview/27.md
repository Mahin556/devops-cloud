## CSI vs StorageClass - What's the Difference?

| Feature | CSI | StorageClass |
|---------|-----|--------------|
| **What it is** | Plugin/driver for storage vendor | Abstraction layer for users |
| **Who provides** | Storage vendor (AWS, NetApp, etc.) | Kubernetes admin |
| **Purpose** | Connects Kubernetes to storage backend | Defines storage policies and tiers |
| **Interaction** | Talks directly to storage API | Talks to CSI provisioner |
| **User-facing** | No (users don't directly use CSI) | Yes (users reference in PVC) |

### Key Point from Transcript:
"Without CSI, StorageClass has no meaning. StorageClass alone cannot build a volume independently."
