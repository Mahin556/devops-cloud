## How does Kubernetes handle service discovery and load balancing for applications running in the cluster?

**Answer:**

### Role of Kubernetes Services:
- Services expose pods within the cluster or externally
- Provide a **stable virtual IP address** and **DNS name**
- Users hit the Service, which routes to the appropriate pod

### How Load Balancing Works:
- Services use **kube-proxy** for load balancing
- Distributes requests evenly across multiple pod replicas
- Ensures:
  - **High availability**
  - **Fault tolerance**

### Traffic Flow:
```
User → Service (stable IP/DNS) → kube-proxy → Pod (load balanced)
```
