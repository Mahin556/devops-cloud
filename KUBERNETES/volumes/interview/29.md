## If you have LVM on a worker node, how do you use it in Kubernetes?

### Local/HostPath Volume:
- Storage that exists on the **worker node itself**
- Not network-attached storage
- Called **HostPath Volume** or **Local Volume**
- The node's local disk/LVM is formatted, mounted to a folder
- That folder path is used in PV as `hostPath`

### Steps:
1. Format the LVM disk (create filesystem)
2. Mount it to a folder on the worker node
3. Create PV with `hostPath` pointing to that folder
4. This is a **Local Volume**

### Important Notes:
- HostPath/Local volumes are tied to a specific node
- If pod moves to another node, data is NOT available
- Network storage (NFS, EBS, etc.) is accessible from any node
