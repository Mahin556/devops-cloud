## After restarting StatefulSet pods, data or application state is missing.

### Troubleshooting Steps:

```bash
# Step 1: Verify Persistent Volume Claims
kubectl get pvc -l app=<statefulset-name>

# Step 2: Check volume mounts in pods
kubectl describe pod <pod-name>

# Step 3: Validate headless service
kubectl get svc <headless-service-name>

# Step 4: Fix missing volumes and redeploy
# Ensure volumeClaimTemplates is properly configured:
volumeClaimTemplates:
- metadata:
    name: data
  spec:
    accessModes: ["ReadWriteOnce"]
    resources:
      requests:
        storage: 10Gi
```
