## What is a namespace and how is it useful?

**Answer:**

A namespace is used for **dividing cluster resources between multiple users**.

### Use Cases:

1. **Isolation for POC:** Create a namespace for testing/POC work
2. **Access Control:** Only the creator can access that namespace
3. **Environment Separation:** Dev, Staging, Production can have separate namespaces

**Command:**
```bash
kubectl create namespace monitoring
# or
kubectl create -n monitoring
```

### Benefits:
- Different teams can work in isolation
- Resources are bifurcated
- One namespace can't access pods in another namespace (unless configured)
- Acts as a dedicated workspace
