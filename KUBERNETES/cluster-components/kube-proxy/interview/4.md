## Question 5: What is Kube-proxy?

**Answer:** **kube-proxy** is a network proxy that runs on **every node** in a Kubernetes cluster. It implements the **Service concept** by maintaining network rules for pod-to-service communication.

### Key Responsibilities:

| Responsibility | Description |
|----------------|-------------|
| **Service Abstraction** | Makes services accessible via ClusterIP |
| **Load Balancing** | Distributes traffic across pod replicas |
| **Network Rules** | Maintains iptables/IPVS rules for routing |
| **Endpoint Management** | Watches for endpoint changes and updates rules |

### Modes of Operation:

| Mode | Description |
|------|-------------|
| **iptables** | Default; uses iptables rules for routing |
| **IPVS** | More efficient for large clusters; uses IP Virtual Server |
| **userspace** | Legacy mode; slower |

### How It Works:
```
Pod → Service ClusterIP → kube-proxy (iptables rules) → Backend Pod
```
