## How do two containers running in a single pod communicate with each other, and how does this happen internally?

### Part 1 - The Simple Answer:
- Two containers in the same pod can communicate using **localhost**
- They share the same network namespace
- Container A can reach Container B via `localhost:<port>`

### Part 2 - The Internal Mechanism:
**Pause Containers:**
- Kubernetes uses **pause containers** for sharing networking between containers in the same pod
- The pause container is a special container that holds the network namespace
- All other containers in the pod join the pause container's network namespace
- This is why all containers in a pod share the same IP address

### Key Points:
- The pause container is the first container created in every pod
- It provides the shared network namespace
- This is how Kubernetes handles networking between containers in the same pod
