## The Quorum Formula?

### The Mathematical Formula:

```
Available Votes ≥ (Total Votes / 2) + 1
```

Or more precisely:
```
Quorum = floor(Total Votes / 2) + 1
```

### Examples with Different Cluster Sizes:

**1 Node Cluster:**
```
Total Votes = 1
Quorum = floor(1/2) + 1 = 0 + 1 = 1
Can tolerate 0 failures
If the node fails → cluster is down
```

**2 Node Cluster:**
```
Total Votes = 2
Quorum = floor(2/2) + 1 = 1 + 1 = 2
Can tolerate 0 failures!
If 1 node fails → quorum NOT met → cluster STOPS
This is why 2 nodes gives NO advantage over 1 node
```

**3 Node Cluster:**
```
Total Votes = 3
Quorum = floor(3/2) + 1 = 1 + 1 = 2
Can tolerate 1 failure
If 1 node fails → 2 remain → quorum met → cluster works
If 2 nodes fail → 1 remains → quorum NOT met → cluster STOPS
```

**4 Node Cluster:**
```
Total Votes = 4
Quorum = floor(4/2) + 1 = 2 + 1 = 3
Can tolerate 1 failure
If 1 node fails → 3 remain → quorum met → cluster works

PROBLEM with 4 nodes:
If network splits 2+2:
  Partition A: 2 votes → quorum NOT met (needs 3) → STOPS
  Partition B: 2 votes → quorum NOT met (needs 3) → STOPS
  BOTH partitions stop → cluster DOWN!

This is WORSE than 3 nodes!
```

**5 Node Cluster:**
```
Total Votes = 5
Quorum = floor(5/2) + 1 = 2 + 1 = 3
Can tolerate 2 failures
```
