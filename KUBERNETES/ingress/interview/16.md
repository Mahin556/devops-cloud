#### Q5: How does Ingress help in Kubernetes?
**Detailed Answer:**
While `kube-proxy` handles **L4 (TCP/UDP)** traffic routing, **Ingress** handles **L7 (HTTP/HTTPS)** traffic.

**Limitations of NodePort/LoadBalancer without Ingress:**
- Each LoadBalancer service in the cloud costs money (approx $15-20/month per LB).
- You cannot do path-based routing (`app.com/api` -> Service A, `app.com/web` -> Service B) easily.

**How Ingress Solves This:**
- **Single Entry Point:** You deploy **one** LoadBalancer for the **Ingress Controller** (e.g., Nginx Ingress, Traefik, AWS ALB Controller).
- **Path/Host Routing:** The Ingress Controller reads **Ingress Resources** (YAML files) to route traffic based on hostname and URL path to different internal ClusterIP services.
- **TLS Termination:** Handles SSL certificates for HTTPS at the edge.
