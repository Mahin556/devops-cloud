## Cluster Autoscaler fails to add nodes during high workload demand.

### Troubleshooting Steps:

```bash
# Step 1: Inspect Autoscaler logs
kubectl logs -n kube-system deployment/cluster-autoscaler

# Step 2: Verify resource requests
resources:
  requests:
    cpu: "500m"
    memory: "512Mi"

# Step 3: Check scaling limits
kubectl describe configmap cluster-autoscaler-config -n kube-system

# Step 4: Adjust node group size (AWS example)
aws autoscaling set-desired-capacity \
  --auto-scaling-group-name <asg-name> \
  --desired-capacity <new-size>
```
