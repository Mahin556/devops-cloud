## Commands to Find etcd Leader?

### Method 1: Using kubectl
```bash
# Describe etcd pod
kubectl describe pod etcd-master-1 -n kube-system | grep -i leader

# Or check all etcd pods
kubectl get pods -n kube-system | grep etcd
kubectl logs etcd-master-1 -n kube-system | grep -i leader
```

### Method 2: Using etcdctl
```bash
# SSH into any master node
# Run etcdctl command inside etcd container

kubectl exec -it etcd-master-1 -n kube-system -- sh

# Check member list
etcdctl member list

# Output shows which node is leader:
# 8e9e05c52164694d: name=master-1 peerURLs=http://10.0.0.1:2380 clientURLs=http://10.0.0.1:2379 isLeader=false
# a9f0f5c52164694d: name=master-2 peerURLs=http://10.0.0.2:2380 clientURLs=http://10.0.0.2:2379 isLeader=true
# b1c2d3e4f5216469: name=master-3 peerURLs=http://10.0.0.3:2380 clientURLs=http://10.0.0.3:2379 isLeader=false

# Check endpoint status
etcdctl endpoint status --endpoints=10.0.0.1:2379,10.0.0.2:2379,10.0.0.3:2379
```
