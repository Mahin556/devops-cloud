## How Does Service Discover Pods?

**Answer:** Through **Labels and Selectors**

### How it works:
- Pods are assigned labels (e.g., `app=nginx`)
- Service has a selector (e.g., `selector: app: nginx`)
- If pod's label matches the service's selector, the pod is automatically associated
- No manual attachment needed

### Intelligence in `kubectl expose` command:
- When you run `kubectl expose pod ram`, the command:
  1. Reads the pod's specification
  2. Automatically extracts the pod's labels
  3. Uses those labels as the service selector
  4. Associates the pod with the service automatically
