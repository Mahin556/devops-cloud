```bash
┌────────────────────────────────────────────────────────────┐
│ WHAT IS hostpath-sc ?                                      │
├────────────────────────────────────────────────────────────┤
│ • Just a custom StorageClass name                          │
│ • Used as a LABEL to match PV and PVC                      │
│ • Does NOT create storage                                  │
│ • Real storage must be created manually on node            │
│ • Helps scheduler when using node-based storage            │
└────────────────────────────────────────────────────────────┘
```


##### StorageClass (only for matching + scheduling)

```yaml
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: hostpath-sc

# This provisioner means:
# Kubernetes WILL NOT create storage automatically
provisioner: kubernetes.io/no-provisioner

# Binding waits until a Pod uses the PVC
# Helps scheduler choose correct node before PV binding
volumeBindingMode: WaitForFirstConsumer
```


##### Manual PV (this is the REAL storage)

```yaml
apiVersion: v1
kind: PersistentVolume
metadata:
  name: hostpath-pv
spec:
  capacity:
    storage: 1Gi
  accessModes:
    - ReadWriteOnce

  # Must match StorageClass name
  storageClassName: hostpath-sc

  persistentVolumeReclaimPolicy: Retain

  # Actual storage on node filesystem
  hostPath:
    path: /mnt/data/vol
    type: DirectoryOrCreate

  # Tells Kubernetes this storage lives on node01 only
  nodeAffinity:
    required:
      nodeSelectorTerms:
      - matchExpressions:
        - key: kubernetes.io/hostname
          operator: In
          values:
          - node01
```

##### PVC (request for storage)

```yaml
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: http-claim
spec:
  accessModes:
    - ReadWriteOnce

  # Must match PV storageClassName
  storageClassName: hostpath-sc

  resources:
    requests:
      storage: 1Gi
```

##### How binding happens (theory)

```bash
PVC created
   ↓
Pod created using PVC
   ↓
Scheduler selects node
   ↓ (because WaitForFirstConsumer)
Kubernetes looks for PV:
   • same storageClassName
   • enough storage
   • correct access mode
   • nodeAffinity matches node
   ↓
PVC gets Bound to PV
```
