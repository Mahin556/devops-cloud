## Interview Question Quick Reference

| # | Question | Answer |
|---|----------|--------|
| 1 | What is Reclaim Policy? | Controls PV and data lifecycle when PVC is deleted |
| 2 | Types of Reclaim Policy? | Recycle, Retain, Delete |
| 3 | What is Recycle? | PV becomes Available, data is scrubbed |
| 4 | What is Retain? | PV becomes Released, data is preserved |
| 5 | What is Delete? | PV and data are deleted |
| 6 | Types of Access Modes? | RWO, ROX, RWX, RWOP |
| 7 | What is RWO? | Single node can read-write; multiple pods on that node can write |
| 8 | What is RWX? | Multiple nodes can read-write |
| 9 | What is RWOP? | Only ONE pod can write (newest mode) |
| 10 | Why RWOP was introduced? | To prevent data corruption when multiple pods on same node write |
| 11 | PV Status types? | Available, Bound, Released, Failed |
| 12 | When does PV go to Released? | When Retain policy and PVC is deleted |
| 13 | When does PV go to Available from Bound? | When Recycle policy and PVC is deleted |
| 14 | When does Failed state occur? | Storage connectivity or backend issues |
