## What Are the Limitations of NodePort?

**Key Limitations (Interview Question):**

1. **IP-based access:** External users access via IP address, not domain name. Clients don't use IPs in the real world.

2. **Node failure:** If the node whose IP you gave goes down, the service becomes unavailable.

3. **Port conflicts:** Multiple services need different nodePorts; managing port assignments becomes complex.

4. **Security concerns:** Exposing node IPs and ports directly to external users is a security risk.

5. **Firewall overhead:** Each new port number must be whitelisted in the firewall repeatedly.

6. **Multiple ports exposed:** Attackers can target exposed port numbers.
