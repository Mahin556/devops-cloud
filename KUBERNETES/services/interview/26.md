## How to Verify Service-to-Pod Mapping?

### Commands:

**Method 1: Describe the service**
```bash
kubectl describe svc <service-name>
```
Look for the `Endpoints` section - it shows the pod IPs.

**Method 2: Get endpoints directly**
```bash
kubectl get endpoints
# or
kubectl get ep
```
This shows which pod IPs are mapped to each service.
