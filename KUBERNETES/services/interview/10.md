## What is NodePort Service?

**Definition:** NodePort exposes the service on each Node's IP at a static port, allowing external access.

**Why NodePort was introduced:**
- ClusterIP only works internally
- To access applications from outside the cluster, NodePort was created

**Port Range:** **30000-32767** (approximately 2767 ports available)

**Three Ports in NodePort:**

| Port | Description | Can You Choose? |
|------|-------------|------------------|
| **targetPort** | Container's application port | NO (must match app) |
| **port** | Service/proxy port (internal) | YES |
| **nodePort** | External port on each node (30000-32767) | YES (within range) |

**Traffic Flow:**
```
Client → NodeIP:NodePort → Service → Pod (targetPort)
```

**Key Point from Transcript:**
- You can use ANY node's IP, not just the node where the pod is running
- This works because **every node has kube-proxy** with the same service information
- kube-proxy on each node knows about all services and their endpoints
