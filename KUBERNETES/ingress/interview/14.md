## What do you understand by Ingress default backend?

**Answer:**

The default backend specifies **what to do with incoming requests that don't match any defined rules**.

- If an HTTP request comes in and there's no rule defined for it
- The default backend handles where to divert/send that incoming request
- It's **recommended to define** a default backend
- Without it, you'll get unclear error messages
- With it configured, you get clear messages about what's happening
