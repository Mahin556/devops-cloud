The Container Storage Interface (CSI) is a standard that allows storage systems (like block and file storage) to be exposed to container orchestrators like Kubernetes. Instead of being hardcoded into the Kubernetes core, storage providers can now write their own CSI drivers that are installed separately, making Kubernetes more modular and extensible.

Here is a comprehensive list of production-grade CSI drivers categorized by provider or technology.

### 🔍 How to Choose a CSI Driver

The official Kubernetes CSI documentation provides a comprehensive table of drivers. For a more searchable and filterable experience, you can also use community resources like **StorageClass.info**, which indexes over 150 drivers.
