## What is Trivy?
- Open-source security scanner (Aqua Security)
- Scans images, file systems, repos, clusters
- Fast, simple, beginner-friendly
- One-command vulnerability scanning

---

## Why does Trivy exist?
- Container images often have outdated packages
- Security risks increase with microservices
- Need for fast, automated scanning
- DevSecOps requires early detection

---

## What are CVEs?
- Common Vulnerabilities and Exposures
- Each CVE has ID + severity + description + fix
- Used globally for vulnerability tracking
- Trivy pulls from trusted vulnerability databases

---

## Trivy in DevSecOps
Trivy helps with:
- Image scanning
- Repo & FS scanning
- Kubernetes security
- CI/CD pipeline integration
- Shift-left security
