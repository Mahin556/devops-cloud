## Who Maintains/Maps Service IP to Pod IP?

**Answer:** **kube-proxy**

### Role of kube-proxy:
- kube-proxy is a service that runs on every node
- It maintains the mapping between Service IP and Pod IPs
- When traffic arrives at the Service IP, kube-proxy redirects it to the appropriate pod
- It provides stable IP for dynamic pod IPs

### How it works:
1. Service IP is created (stable, virtual IP)
2. kube-proxy watches for service and endpoint updates
3. kube-proxy creates iptables rules to redirect traffic
4. Traffic to Service IP → kube-proxy → correct Pod
