### Expose multiple services using a single Ingress resource. `/api` routes to API service, `/ui` routes to frontend service, unmatched paths return custom 404.

**Solution:**

```yaml
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: main-ingress
  annotations:
    nginx.ingress.kubernetes.io/rewrite-target: /
spec:
  ingressClassName: nginx
  defaultBackend:
    service:
      name: custom-404-service
      port:
        number: 80
  rules:
  - http:
      paths:
      - path: /api
        pathType: Prefix
        backend:
          service:
            name: api-service
            port:
              number: 80
      - path: /ui
        pathType: Prefix
        backend:
          service:
            name: frontend-service
            port:
              number: 80
```

**Custom 404 Service:**
```yaml
apiVersion: v1
kind: Service
metadata:
  name: custom-404-service
spec:
  selector:
    app: custom-404
  ports:
  - port: 80
    targetPort: 80
---
apiVersion: apps/v1
kind: Deployment
metadata:
  name: custom-404
spec:
  replicas: 1
  selector:
    matchLabels:
      app: custom-404
  template:
    metadata:
      labels:
        app: custom-404
    spec:
      containers:
      - name: nginx
        image: nginx:latest
        command: ["/bin/sh", "-c"]
        args:
        - |
          echo '{"error": "Not Found", "message": "The requested path does not exist"}' > /usr/share/nginx/html/404.json
          cat > /etc/nginx/conf.d/default.conf << 'EOF'
          server {
              listen 80;
              location / {
                  return 404 '{"error":"Not Found","message":"The requested path does not exist"}';
                  default_type application/json;
              }
          }
          EOF
          nginx -g 'daemon off;'
```

**Traffic Flow:**
```
Request to /api/users  → api-service:80
Request to /ui/dashboard → frontend-service:80
Request to /admin       → custom-404-service:80 (default backend)
```

**Key Points:**
- Single Ingress resource handles all routing
- `pathType: Prefix` matches `/api`, `/api/users`, `/api/v1/data`, etc.
- Routes defined under `rules.http.paths`
- `defaultBackend` acts as catch-all for unmatched paths
- Custom 404 service returns JSON error response
- No need for multiple Ingress resources
- Path-based routing keeps external URLs clean
