## Important Notes from Transcript:

**Key Dependency Chain:**
```
PV Expansion depends on:
1. Dynamic Provisioning (StorageClass + CSI)
2. Backend Storage expansion capability
3. allowVolumeExpansion: true in StorageClass
```

**If any one condition is missing, expansion WILL FAIL.**

**For Static PVs:**
- Cannot be expanded online
- Must create a new larger PV
- Migrate data manually
- This is why dynamic provisioning is preferred for production
