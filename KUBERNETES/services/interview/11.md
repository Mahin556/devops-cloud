## LoadBalancer Service Type

**Question:** What does creating a Service with `type: LoadBalancer` mean?

**Answer:** It means integrating your service with a **Network Load Balancer (Layer 3/4)**.

### In Cloud (EKS, GKE, AKS):
- Automatically provisions a cloud load balancer (AWS NLB, Azure LB, etc.)
- Assigns an external IP automatically
- No manual configuration needed

### On-Premises:
- Requires **MetalLB** to be installed first
- MetalLB provides an IP from its pool
- Connects the service at the network level automatically
