## Role of etcd in Kubernetes

`etcd` is a distributed, highly available key-value database used by Kubernetes to store all cluster data and configuration.

It acts as the **single source of truth** for the Kubernetes cluster.

---

## What etcd Stores

### 1. Desired State

Stores Kubernetes resource definitions such as:

* Deployments
* Services
* ConfigMaps
* Secrets

### 2. Current State

Stores real-time cluster information like:

* Running Pods
* Node status
* Cluster health

### 3. Metadata

Stores:

* Cluster configuration
* Access control policies
* Runtime information

---

## Importance of etcd

* Maintains cluster consistency
* Enables fault tolerance
* Supports high availability
* Critical for Kubernetes operations

If `etcd` data is lost, the Kubernetes cluster state can also be lost.

---

### Simple Interview Answer

“etcd is a distributed key-value store used by Kubernetes as its central database. It stores the desired state, current state, configuration, and metadata of the entire Kubernetes cluster.”
