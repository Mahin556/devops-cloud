## Can We Migrate a Service IP from One Deployment to Another?

**Answer:** YES, with conditions.

### Scenario:
- Service was pointing to Deployment-A
- Deployment-A is accidentally deleted
- You want the SAME service IP to point to Deployment-B

### What Needs to Change:
1. **Target Port:** If the new application uses a different port, update the target port
2. **Selector:** The new deployment's pod labels must match the service's selector

### How to Update:
```bash
kubectl edit svc <service-name>
```
Change the selector and target port to match the new deployment.

### Key Point:
- Service IP is NOT hard-bound to any deployment
- It can be migrated to any deployment as long as:
  - Selector matches the new pod labels
  - Target port matches the new application port
