## What is Service IP Pool and How to Find It?

### Service IP Pool:
- Default: `10.96.0.0/12` (or similar)
- This is separate from the Pod IP pool
- Used for ClusterIP services

### How to Check Service IP Range:

**Method 1: Check kubeadm config map**
```bash
kubectl get cm -n kube-system kubeadm-config -o yaml
```

**Method 2: Check API Server configuration**
```bash
# Look in API server manifest
cat /etc/kubernetes/manifests/kube-apiserver.yaml | grep service-cluster-ip-range
```

**Method 3: Check individual services**
```bash
kubectl get svc
kubectl get svc -A
```

### Three IP Pools in Kubernetes:
| Pool | Purpose | Example Range |
|------|---------|---------------|
| **Pod Network** | IPs for pods | 172.16.0.0/16 |
| **Service Network** | IPs for ClusterIP services | 10.96.0.0/12 |
| **Node Network** | Physical infrastructure IPs | 192.168.1.0/24 |
