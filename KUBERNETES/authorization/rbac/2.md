
# PART 2 — Create RBAC permissions for Jane

We want:

### Jane in `red`

```text
GET secrets
```

### Jane in `blue`

```text
GET secrets
LIST secrets
```

The lesson explicitly creates these different permissions in the two namespaces. 

---

## 2.1 Create Role in `red`

```bash
kubectl create role secret-manager \
  --verb=get \
  --resource=secrets \
  -n red
```

Check it:

```bash
kubectl get role -n red
```

Describe it:

```bash
kubectl describe role secret-manager -n red
```

Expected conceptually:

```text
Name: secret-manager

Resources:
  secrets

Verbs:
  get
```

---

# 3. Create RoleBinding in `red`

Now we need to give the Role to Jane.

```bash
kubectl create rolebinding secret-manager \
  --role=secret-manager \
  --user=Jane \
  -n red
```

Check:

```bash
kubectl get rolebinding -n red
```

Describe:

```bash
kubectl describe rolebinding secret-manager -n red
```

The relationship is:

```text
Jane
  │
  ▼
RoleBinding: secret-manager
  │
  ▼
Role: secret-manager
  │
  ▼
GET secrets
  │
  ▼
namespace red
```

Remember:

> **Role = what permissions?**

> **RoleBinding = who gets those permissions?**

The lesson describes exactly this separation.

# PART 10 — Important ClusterRole + RoleBinding example

The lesson also creates permissions for **Jim**.

Goal:

```text
Jim
 ↓
delete deployments
 ↓
ONLY red namespace
```

We already have:

```text
ClusterRole: deploy-deleter
```

Instead of a ClusterRoleBinding, create a **RoleBinding in `red`**.

```bash
kubectl create rolebinding deploy-deleter \
  --clusterrole=deploy-deleter \
  --user=Jim \
  -n red
```

This is a very important combination:

```text
ClusterRole
     +
RoleBinding
     ↓
Permissions from ClusterRole
     ↓
Applied only in the RoleBinding namespace
```

The lesson explicitly demonstrates this combination.

# PART 11 — Now create Jane's certificate

Now we move from **authorization** to **authentication**.

We need:

```text
jane.key
jane.csr
jane.crt
```

The lesson's certificate process starts by generating a key, creating a CSR with CN `Jane`, submitting it to Kubernetes, approving it, and retrieving the signed certificate. 

---

# 12. Generate Jane's private key

Use OpenSSL:

```bash
openssl genrsa -out jane.key 2048
```

Check:

```bash
ls -l jane.key
```

You now have:

```text
jane.key
```

This is Jane's **private key**.

Protect it:

```bash
chmod 600 jane.key
```

---

# PART 13 — Generate Jane's CSR

Now create a CSR:

```bash
openssl req -new \
  -key jane.key \
  -out jane.csr \
  -subj "/CN=Jane"
```

Now:

```bash
ls -l jane.csr
```

You have:

```text
jane.key
jane.csr
```

The critical part is:

```text
CN=Jane
```

Because:

```text
CN=Jane
   ↓
Kubernetes username = Jane
```

The lesson specifically emphasizes this CN → username relationship. 

---

# PART 14 — Inspect the CSR

You can verify it:

```bash
openssl req -in jane.csr -noout -text
```

Look for:

```text
Subject:
    CN = Jane
```

---

# PART 15 — Base64 encode the CSR

The Kubernetes CSR object needs the CSR data encoded.

Use:

```bash
cat jane.csr | base64 | tr -d '\n'
```

Or:

```bash
base64 -w 0 jane.csr
```

Save the result mentally/copy it.

You will put it into:

```yaml
spec:
  request: <BASE64-ENCODED-CSR>
```

The lesson explicitly describes base64 encoding the CSR and placing it in the Kubernetes CSR resource. 

---

# PART 16 — Create Kubernetes CSR YAML

Create:

```bash
vim jane-csr.yaml
```

Use:

```yaml
apiVersion: certificates.k8s.io/v1
kind: CertificateSigningRequest
metadata:
  name: jane
spec:
  request: <BASE64-ENCODED-JANE-CSR>
  signerName: kubernetes.io/kube-apiserver-client
  usages:
    - client auth
```

Replace:

```text
<BASE64-ENCODED-JANE-CSR>
```

with the output from:

```bash
base64 -w 0 jane.csr
```

The lesson describes creating a Kubernetes `CertificateSigningRequest` object and putting the base64-encoded CSR into its `request` field. 

---

# PART 21 — Get Jane's signed certificate

The certificate is stored in:

```text
.status.certificate
```

Retrieve it:

```bash
kubectl get csr jane \
  -o jsonpath='{.status.certificate}' \
  | base64 -d > jane.crt
```

Now:

```bash
ls -l jane.crt
```

You have:

```text
jane.key
jane.csr
jane.crt
```

The lesson describes retrieving the base64-encoded certificate from the CSR, decoding it, and saving it as `jane.crt`. 

---

# PART 22 — Verify Jane's certificate

Run:

```bash

```

Check:

```text

    CN = Jane
```

You can also check issuer:

```bash

```

And validity:

```bash

```

You should have:

```text
notBefore=...
notAfter=...
```

# PART 38 — The 4 RBAC resources you must memorize

The entire RBAC section boils down to these four:

```text
                    RBAC
                     │
       ┌─────────────┴─────────────┐
       │                           │
   Namespaced                  Cluster
       │                           │
    ┌──┴──┐                    ┌───┴────┐
    │     │                    │        │
  Role  RoleBinding       ClusterRole  ClusterRoleBinding
```

Think:

```text
ROLE
"What can be done?"

ROLEBINDING
"Who gets it?"

CLUSTERROLE
"What cluster-level/reusable permissions exist?"

CLUSTERROLEBINDING
"Who gets those permissions cluster-wide?"
```

The lesson's final recap specifically identifies Roles, ClusterRoles, RoleBindings, ClusterRoleBindings, `can-i`, certificates, and CertificateSigningRequests as the major topics. 

## And the certificate side is just this:

```text
                 AUTHENTICATION

       openssl genrsa
             │
             ▼
        jane.key
             │
             ▼
       openssl req
             │
             ▼
        jane.csr
        CN = Jane
             │
             ▼
    Kubernetes CSR object
             │
             ▼
   kubectl certificate approve
             │
             ▼
        jane.crt
             │
             ├─────────────┐
             ▼             ▼
        jane.key       jane.crt
             │             │
             └──────┬──────┘
                    ▼
                kubeconfig
                    │
                    ▼
              kubectl / API

                    ▼
                  Jane
                    │
                    ▼
                   RBAC
                    │
```

That is the **full hands-on process represented by your screenshot and the attached RBAC lesson**.
