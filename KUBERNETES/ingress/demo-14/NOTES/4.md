This is because **capture groups only capture what is inside the parentheses `()`**.

Look at your regex:

```regex
/api(/|$)(.*)
```

Let's number the parts:

```text
/api (/|$) (.*)
      ↑      ↑
     $1     $2
```

Notice that:

* `/api` is **outside** any parentheses.
* `(/|$)` is the **first** capture group.
* `(.*)` is the **second** capture group.

Only the parts inside `()` become `$1`, `$2`, etc.

---

## Example 1

Request:

```text
/api/users
```

Match:

```text
/api/users
|||| |||||
|||| └───── $2 = users
└────────── literal "/api"
     └───── $1 = /
```

Result:

| Expression | Value                        |
| ---------- | ---------------------------- |
| `/api`     | Literal match (not captured) |
| `$1`       | `/`                          |
| `$2`       | `users`                      |

---

## Example 2

Request:

```text
/api
```

Match:

```text
/api
|||| 
└── literal "/api"
```

Here:

* `(/|$)` matches the **end of the string** (`$`).
* `(.*)` matches an empty string.

So:

| Group | Value                                |
| ----- | ------------------------------------ |
| `$1`  | *(end of string, effectively empty)* |
| `$2`  | *(empty)*                            |

---

## If you wanted `$1` to contain `/api`

You would need to put `/api` inside the parentheses:

```regex
(/api)(/|$)(.*)
```

Now the groups are:

```text
(/api)(/|$)(.*)
  ↑      ↑    ↑
 $1     $2   $3
```

For `/api/users`:

| Group | Value   |
| ----- | ------- |
| `$1`  | `/api`  |
| `$2`  | `/`     |
| `$3`  | `users` |

### Key rule to remember

Only **parentheses `()` create capture groups**.

```regex
abc(def)(ghi)
```

| Part    | Captured? |
| ------- | --------- |
| `abc`   | ❌ No      |
| `(def)` | ✅ `$1`    |
| `(ghi)` | ✅ `$2`    |

This is why, in the common ingress regex:

```regex
/ api ( /|$ ) ( .* )
```

* `/api` is matched but **not captured**.
* `(/|$)` becomes `$1`.
* `(.*)` becomes `$2`.

This is intentional because the rewrite only needs the part **after** `/api`, so `rewrite-target: /$2` cleanly removes the `/api` prefix.
