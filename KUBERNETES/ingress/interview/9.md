## Ingress Controller Architecture

### Three Components:
1. **Ingress Controller Pods** - Run on specific worker nodes (e.g., 2 nodes for HA)
2. **External Load Balancer** - In front of Ingress Controller pods (for HA)
3. **Ingress Resource/Rules** - Define routing rules (path-based, host-based)

### Ports:
- Ingress Controller listens on **80** (HTTP) and **443** (HTTPS)
- These ports are exposed via NodePort on the worker nodes

### Why External LB Still Needed:
- Not for individual services anymore
- Only for the **Ingress Controller itself** (for high availability)
- Single external LB for the entire cluster (not per service)
