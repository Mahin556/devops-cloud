### Application needs guaranteed minimum CPU of 250m and memory of 256Mi, but should not exceed limits of 500m CPU and 512Mi memory.

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: resource-pod
spec:
  containers:
  - name: app-container
    image: your-app-image
    resources:
      requests:
        cpu: "250m"
        memory: "256Mi"
      limits:
        cpu: "500m"
        memory: "512Mi"
```

Container won't be scheduled if node can't meet requests

Container will be throttled/throttled or OOM killed if it exceeds limits
