## Why Pod IP is Not Static? How to Solve This?

**Problem:** Pod IPs are NOT static. When a pod restarts or moves to another node, its IP changes.

**Example Scenario:**
- Database pod was on Node-1 with IP 172.16.1.5
- Pod restarts and moves to Node-2
- New IP becomes 172.16.2.10
- Application team would need to update the database IP every time
- This is NOT practical

**Solution:** **Kubernetes Service**

A Service provides:
- **Stable networking** for pods
- A fixed IP address that doesn't change
- Load balancing across pod replicas
- Service IP remains constant even if pod IPs change
