### What are Liveness, Readiness, and Startup Probes in Kubernetes

## Probes in Kubernetes

Kubernetes uses probes to check the health and status of containers. These probes are performed by the Kubelet to ensure applications run reliably.

### 1. Liveness Probe

* Checks whether the container is still running properly.
* If the probe fails:

  * Kubernetes restarts the container.
* Used to detect:

  * Deadlocks
  * Hung or crashed applications

### 2. Readiness Probe

* Checks whether the container is ready to receive traffic.
* If the probe fails:

  * The Pod is removed from Service endpoints.
* Used when:

  * Application is still loading
  * Temporary heavy processing is happening

### 3. Startup Probe

* Checks whether the application has started successfully.
* Disables liveness and readiness checks until startup completes.
* Useful for slow-starting applications.

---

| Probe           | Purpose                         | Action on Failure           |
| --------------- | ------------------------------- | --------------------------- |
| Liveness Probe  | Checks if app is alive          | Restarts container          |
| Readiness Probe | Checks if app can serve traffic | Removes Pod from Service    |
| Startup Probe   | Checks app startup status       | Prevents premature restarts |

---

### Simple Interview Answer

“In Kubernetes, probes are health checks used to monitor containers. Liveness Probe checks if the container is alive, Readiness Probe checks if it is ready to serve traffic, and Startup Probe checks whether the application has started successfully.”
