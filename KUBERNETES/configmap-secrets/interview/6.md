### How to mount an external JSON config file into a container at a specific path without rebuilding the image.

Solution:

Step 1 - Create ConfigMap from JSON file:

```bash
kubectl create configmap app-config --from-file=config.json
```

Or with YAML:

```yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: app-config
data:
  config.json: |
    {
      "database": {
        "host": "localhost",
        "port": 5432
      },
      "logging": {
        "level": "info"
      }
    }
```

Step 2 - Mount ConfigMap as Volume:

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: app-deployment
spec:
  replicas: 1
  selector:
    matchLabels:
      app: myapp
  template:
    metadata:
      labels:
        app: myapp
    spec:
      containers:
      - name: app-container
        image: myapp:latest
        volumeMounts:
        - name: config-volume
          mountPath: /etc/app/config.json
          subPath: config.json
      volumes:
      - name: config-volume
        configMap:
          name: app-config
```

Key Points:
- Feature used: ConfigMap with Volume Mount
- ConfigMap stores the JSON file content
- Volume mount places the file at a specific path in the container
- `subPath` ensures only the specific file is mounted (not the entire directory)
- No image rebuild required when configuration changes
- Container sees the JSON file at the exact path specified
