#### Q6: List the different types of Services in Kubernetes.
| Type | Description | Use Case |
| :--- | :--- | :--- |
| **ClusterIP** | **Default.** Exposes the service on an internal IP only reachable within the cluster. | Internal microservice communication (e.g., Frontend talking to Backend API). |
| **NodePort** | Opens a static port (30000-32767) on **every** node's IP address. Traffic to `<NodeIP>:<NodePort>` is routed to the service. | Development/testing quick access; not recommended for production due to security/firewall complexity. |
| **LoadBalancer** | Integrates with cloud provider to provision an external load balancer (AWS NLB/ALB, GCP LB). Assigns a public IP to the service. | Exposing a single application to the internet without Ingress. |
| **ExternalName** | Maps a service to a DNS `CNAME` record. No proxying is done. | Accessing a database or service hosted **outside** the Kubernetes cluster (e.g., an RDS instance) using an internal DNS alias. |
