Here's the complete setup — all three resources explained with your exact port configuration from the values.yaml.

## How the three resources connect

```
GatewayClass          Gateway              HTTPRoute
(cluster-scoped)      (namespaced)         (namespaced)
     │                    │                    │
     │  controllerName    │  gatewayClassName  │  parentRefs
     └──► Traefik ◄───────┘                    │
                          │ ◄──────────────────┘
                          │
                    listeners:
                    - port: 8000 (web/HTTP)
                    - port: 8443 (websecure/HTTPS)
```

## Step 1 — GatewayClass (create once, cluster-wide)

The GatewayClass is a cluster-scoped resource. The following GatewayClass defines that gateways attached to it must be managed by the Traefik controller.

```yaml
# gatewayclass.yaml
apiVersion: gateway.networking.k8s.io/v1
kind: GatewayClass
metadata:
  name: traefik
spec:
  controllerName: traefik.io/gateway-controller
  # This MUST match what Traefik expects — do not change this string
```

```bash
kubectl apply -f gatewayclass.yaml

# Verify Traefik accepted it:
kubectl describe gatewayclass traefik
# Look for: Accepted: True in Conditions
```

---

## Step 2 — Gateway (ties listeners to the GatewayClass)

Your values.yaml has `web.port: 8000` and `websecure.port: 8443` — these are the **container ports Traefik listens on**. Your Gateway listeners must match these ports exactly.

### HTTP only (simplest — start here)
```yaml
# gateway-http.yaml
apiVersion: gateway.networking.k8s.io/v1
kind: Gateway
metadata:
  name: traefik-gateway
  namespace: default          # put it in same namespace as your HTTPRoutes
spec:
  gatewayClassName: traefik   # must match GatewayClass name above

  listeners:
    - name: web
      protocol: HTTP
      port: 8000              # matches your values.yaml web.port
      allowedRoutes:
        namespaces:
          from: All           # All = routes from any namespace can attach
                              # Same = only routes from THIS namespace
```

### HTTP + HTTPS (with TLS)
```yaml
# gateway-full.yaml
apiVersion: gateway.networking.k8s.io/v1
kind: Gateway
metadata:
  name: traefik-gateway
  namespace: default
spec:
  gatewayClassName: traefik
  listeners:
    # HTTP listener
    - name: web
      protocol: HTTP
      port: 8000
      allowedRoutes:
        namespaces:
          from: All

    # HTTPS listener — needs a TLS secret
    - name: websecure
      protocol: HTTPS
      port: 8443              # matches your values.yaml websecure.port
      tls:
        mode: Terminate       # Traefik terminates TLS, forwards HTTP to backend
        certificateRefs:
          - kind: Secret
            name: my-tls-secret       # must exist in same namespace as Gateway
            namespace: default
      allowedRoutes:
        namespaces:
          from: All
```

Create the TLS secret first if using HTTPS:
```bash
# Self-signed for testing:
openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
  -keyout tls.key -out tls.crt \
  -subj "/CN=demo.local"

kubectl create secret tls my-tls-secret \
  --cert=tls.crt \
  --key=tls.key \
  -n default
```

```bash
kubectl apply -f gateway-full.yaml

# Verify Gateway is ready:
kubectl describe gateway traefik-gateway -n default
# Look for: Programmed: True in Conditions
# And each listener shows: Accepted: True
```

## Step 3 — HTTPRoute

A Route resource must be configured with ParentRefs that reference the parent Gateway it should be associated with.

### Basic — route all traffic to one service
```yaml
# httproute-basic.yaml
apiVersion: gateway.networking.k8s.io/v1
kind: HTTPRoute
metadata:
  name: my-app-route
  namespace: default
spec:
  parentRefs:
    - name: traefik-gateway   # must match Gateway name
      namespace: default      # namespace where the Gateway lives
      sectionName: web        # which listener — matches the listener "name:" field

  hostnames:
    - "demo.local"            # incoming Host header must match this

  rules:
    - matches:
        - path:
            type: PathPrefix
            value: /
      backendRefs:
        - name: my-service    # your Service name
          port: 80
```

### Path-based routing (multiple backends)
```yaml
# httproute-paths.yaml
apiVersion: gateway.networking.k8s.io/v1
kind: HTTPRoute
metadata:
  name: multi-path-route
  namespace: default
spec:
  parentRefs:
    - name: traefik-gateway
      namespace: default
      sectionName: web

  hostnames:
    - "demo.local"

  rules:
    # /api/* → api-service
    - matches:
        - path:
            type: PathPrefix
            value: /api
      backendRefs:
        - name: api-service
          port: 8080

    # /app/* → frontend-service
    - matches:
        - path:
            type: PathPrefix
            value: /app
      backendRefs:
        - name: frontend-service
          port: 3000

    # Everything else → default-service
    - matches:
        - path:
            type: PathPrefix
            value: /
      backendRefs:
        - name: default-service
          port: 80
```

### HTTPS route (attaches to websecure listener)
```yaml
# httproute-https.yaml
apiVersion: gateway.networking.k8s.io/v1
kind: HTTPRoute
metadata:
  name: secure-route
  namespace: default
spec:
  parentRefs:
    - name: traefik-gateway
      namespace: default
      sectionName: websecure  # ← attaches to the HTTPS listener
    - name: traefik-gateway
      namespace: default
      sectionName: web        # ← also receives on HTTP (for redirect)

  hostnames:
    - "demo.local"

  rules:
    - matches:
        - path:
            type: PathPrefix
            value: /
      backendRefs:
        - name: my-service
          port: 80
```

## Complete test with whoami app

```yaml
# full-test.yaml — deploys everything for a quick test
---
apiVersion: apps/v1
kind: Deployment
metadata:
  name: whoami
  namespace: default
spec:
  replicas: 2
  selector:
    matchLabels:
      app: whoami
  template:
    metadata:
      labels:
        app: whoami
    spec:
      containers:
        - name: whoami
          image: traefik/whoami
---
apiVersion: v1
kind: Service
metadata:
  name: whoami
  namespace: default
spec:
  selector:
    app: whoami
  ports:
    - port: 80
      targetPort: 80
---
apiVersion: gateway.networking.k8s.io/v1
kind: HTTPRoute
metadata:
  name: whoami-route
  namespace: default
spec:
  parentRefs:
    - name: traefik-gateway
      namespace: default
      sectionName: web
  hostnames:
    - "whoami.local"
  rules:
    - matches:
        - path:
            type: PathPrefix
            value: /
      backendRefs:
        - name: whoami
          port: 80
```

```bash
kubectl apply -f full-test.yaml

# Test (port-forward since you're on kind/Docker Desktop):
kubectl port-forward -n <traefik-namespace> svc/traefik 8000:8000 &

curl -H "Host: whoami.local" http://localhost:8000
# Should return whoami's response showing headers, IP, etc.
```

## Debug checklist

```bash
# 1. GatewayClass accepted by Traefik:
kubectl get gatewayclass traefik
# ACCEPTED should be True

# 2. Gateway programmed:
kubectl get gateway traefik-gateway -n default
# PROGRAMMED should be True

# 3. HTTPRoute attached to Gateway:
kubectl get httproute -n default
# ATTACHED should show the Gateway name

# 4. Detailed conditions:
kubectl describe httproute whoami-route -n default
# Look under Status.Parents — shows if the route was accepted by the listener

# 5. Traefik logs:
kubectl logs -n <traefik-ns> deploy/traefik | grep -i "gateway\|route\|error"
```
